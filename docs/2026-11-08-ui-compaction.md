# 2026-11-08 UI 压缩改造

用户反馈：
1. 视频 / 图片 Tab 中间的按键提示条占空间（确认后整块按键提示直接移除，不留悬浮入口）。
2. 视频 / 图片页顶部的标题、路径、同步/刷新按钮占据首屏，应收进悬浮入口打开的右侧抽屉（菜单键同效）。
3. 设置 Tab 卡片层数多、行距大，难以快速定位参数。
4. 视频页同步状态需要显示在底部，但不能遮住文件列表。

## 方案

### 按键提示（全局）
- 移除底部通栏 KeyHintBar，同时移除右下角问号悬浮按钮与按键说明抽屉。
- 内容区高度全部还给列表/宫格。

### 视频 / 图片页
- 移除页头（标题、路径、同步/刷新/返回按钮），列表/宫格顶部直接进入内容。
- 右下角 42dp 悬浮按钮打开右侧抽屉，遥控器菜单键同效。
- 视频页抽屉：同步、刷新、返回上级，以及当前选中项的绑定首页/删除操作。
- 图片页抽屉：排序方式与刷新。
- 视频页同步状态改为底部状态条，参与布局不遮挡列表：同步中显示当前目录与进度，完成/失败提示 3s/5s 后自动收起。

### 设置页
- 去掉大标题与每组的独立卡片，改为扁平分组列表（分组标题 + 细分隔线），压缩行距。
- 顶部「文件来源」独占整行，按钮缩为 32dp 高。
- 下方两列：左列「播放 / 字幕」，右列「播放提醒 / 关于」，一屏可见全部参数。
- 倍速 / 步长 / 字幕大小 / 分钟数等选择器缩到 32dp 高，文字 14sp；开关保持原样。
- 右栏二维码卡压缩到 104dp 码图、18dp 内边距。
- 功能不减：新增/修改/删除/测试连接、倍速、步长、字幕大小、双字幕、提醒开关/连续时长/休息时长/结束模式、版本号全部保留。
